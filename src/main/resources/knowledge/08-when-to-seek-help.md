# 何时寻求心理咨询或医疗帮助

状态：候选生产知识；尚未经过心理专业人员复核。最后核验：2026-07-17。

## 求助入口

主动求助是健康责任的一部分。可以从可信任的人、校内心理中心、心理援助热线、综合医院相关科室或精神心理专科等入口开始。心理咨询适合发展、适应、情绪、人际和压力等问题；疑似精神障碍的诊断和治疗属于医疗机构职责。

## 适合考虑专业帮助的情况

压力、焦虑、低落或睡眠困难持续存在，造成明显痛苦，已经影响学习、工作、人际或基本日常功能时，可以考虑专业帮助。频繁不可控日间嗜睡、疑似睡眠呼吸暂停、明显节律紊乱或睡眠中危险行为更适合医疗评估。自评量表只能帮助观察变化，不能作为诊断证明。

## 即时危险

出现自伤、自杀、伤人或迫切危险时，不要等待普通预约。应联系身边可到场的可信任人员，并根据情况联系 `120`、`110` 或所在地紧急服务。`12356` 是全国统一心理援助热线号码，但各地接通方式和服务时间可能不同，不能替代现场紧急处置。

## 不应给出的建议

不要用固定天数、单一量表分数或关键词自动诊断；不要把心理咨询描述成医疗急救；不要给出用药选择、剂量或自行停药建议；不要编造某所学校的预约流程和服务时间。
