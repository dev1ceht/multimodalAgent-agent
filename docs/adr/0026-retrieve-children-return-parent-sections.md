# 检索子块并回填父章节

- Status: Accepted
- Date: 2026-08-12

知识版本使用 `HIERARCHICAL_V1` 分块策略。Markdown 标题或无标题文档的段落组形成语义父块，
父块内部再生成带重叠的检索子块。Elasticsearch 只索引子块：标题路径增强后的 `search_text`
用于 BM25 和 Embedding，原始 `content` 保留为命中正文。

混合召回和重排完成后，应用按父块去重并加载父章节正文。最高分子块的向量 ID、子块序号、
正文偏移量和 PDF 页码继续作为证据溯源；父章节正文受统一字符预算约束。子块重叠不得跨越
父块。完整章节短于子块最小尺寸时保留为单个短子块，避免为了满足尺寸下限而跨越语义边界。
旧 `FLAT_V1` 知识版本继续使用相邻块扩展逻辑。

父子关系保存在数据库和普通 Elasticsearch 字段中，不使用 Elasticsearch join 类型。
知识版本只有在全部子块建立索引并通过数量校验后才能切换为 ACTIVE，保持现有不可变版本和
alias 原子发布约束。
