# 扩大候选集后再重排最终证据

- Status: Accepted
- Date: 2026-08-07

Elasticsearch 通过 KNN、BM25 和 RRF 召回候选证据，生产检索器先按最终 `topK` 的倍数请求候选，
再使用语义相似度与查询关键词覆盖率进行确定性重排，最后截断为最终证据数量。
候选集上限为 100，避免错误配置造成无界查询。

重排策略通过 `EvidenceReranker` 接口隔离。当前实现使用向量分数 75% 与关键词覆盖 25%，不额外调用模型，因此不会把一次用户请求变成不可控的多次模型调用。后续可以在保持检索器编排不变的情况下替换为 cross-encoder 或领域规则实现。

重排只影响证据排序，不改变 ACTIVE 知识版本、Elasticsearch 失败即失败的评测约束，
也不允许本地 baseline 静默替代生产检索。
