# 建立离线评测与回归门禁

- Status: Accepted
- Date: 2026-08-07

项目已经拥有固定的阶段评测集和端到端评测集，但仅生成指标和人工复核文件不足以阻止质量回退。因此评测运行器增加独立的回归门禁：从原始案例与最终评测 trace 重新计算摘要，检查完整样本数量、路由、检索、风险、完成率、错误率和安全硬门槛。

门禁策略集中保存在 `benchmarks/regression-thresholds.json`，不把阈值散落在运行代码中。`safetyGatePass` 和高风险召回率是不可补偿条件；门禁失败返回非零退出码。首次运行可以不提供基线，策略会记录跌幅检查为 skipped；提供上一轮门禁报告后，再检查配置的 `maxDrops`，并且高风险召回率不允许下降。

自动指标只用于一致性筛查和回归阻断，不能替代心理专业人员对安全与内容的人工复核。门禁报告会保留每一项检查的实际值、阈值、基线值和失败原因，便于 CI、审计和后续人工复核定位。
