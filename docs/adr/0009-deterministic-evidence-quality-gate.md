# 在模型复核后保留确定性证据质量门槛

- Status: Accepted
- Date: 2026-08-07

Agentic RAG 的模型复核可以判断证据是否覆盖当前问题，但不能单独决定证据是否可用。复核完成后，系统必须再次检查证据是否具有非空来源、非空正文、有限数值分数，并且至少有一条证据达到 `RAG_MIN_EVIDENCE_SCORE`（默认 0.2）。

质量门槛失败时，RAG 结果仍可保持 `READY`，因为后端确实完成了检索；但 `sufficient` 必须为 `false`，回答上下文必须保留“证据不足”的约束。这样可以区分“检索服务可用”和“检索结果足以支撑回答”，并防止模型复核结果绕过确定性安全规则。

质量判断是无 I/O 的独立模块，评测模式额外记录 `ragEvidenceQualityAccepted`，便于将召回可用性与最终回答质量分开分析。
